# Gillaxediting | Video Editing & Motion Design

We help creators and brands bring their ideas to life through thoughtful editing, motion design, and visual storytelling. Every project is crafted with care, creativity, and attention to detail.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Tech Stack
- **Framework:** React + Vite + TypeScript
- **Styling & Animations:** Tailwind CSS / Motion
- **Deployment:** Vercel
